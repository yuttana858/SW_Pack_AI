# FEFCO / ESBO Code — corrugated and solid board box styles

> **Research note (updated 2026-11-09, wave 2):** the official FEFCO PDFs were opened and read
> in full this wave: the 12th-edition overview [S4], the 12th-edition full interactive edition
> [S20] and the 11th-edition FEFCO/ESBO code [S19]. The FEFCO Code itself contains **only code
> numbers, erection flags (M, A, M/A) and drawings — it gives no style names**. The style
> descriptions below are our own wording of what the official drawings show; common names
> (RSC, FOL, mailer etc.) come from FBA and supplier sources and are marked as such. The code
> is copyrighted: this file summarises it and does not reproduce its drawings or text.

## What the FEFCO Code is

The FEFCO Code (historically the FEFCO–ESBO Code or "International Fibreboard Case Code") is a
numeric catalogue of box and fitment designs for corrugated board and solid board
[S3][S19][S8]. Each design has a four-digit number, so a buyer and a converter in different
countries can name the same construction without translating style names [S20]. The numbers
identify the **construction** (panels, flaps, joint, closure) only; they do not specify board
grade, flute or size.

- The first code was developed in the 1960s by FEFCO and ESBO (then named ASSCO) to avoid
  confusion when communicating in different languages [S20]; FEFCO's web page says "late
  1960s" [S2].
- In the 11th edition additions and changes could be made only by FEFCO and ESBO together
  [S19]; the 12th edition says changes are made only through FEFCO [S20].
- The code is adopted by the ICCA (International Corrugated Case Association), giving it
  worldwide use [S4][S20].
- The code itself states that many other styles and custom designs exist; it lists the common
  ones only [S20].

## Current edition (12th, 2022)

- The **12th edition** was published in **2022** under the title "Design style library for
  corrugated board products" [S1][S4][S20].
- It added **more than 100** designs, including a new series for retail and e-commerce
  packaging (family 08) [S1][S2][S20]. New codes are flagged "new" on each series overview
  page, and the full edition has a "List of NEW designs" [S4][S20].
- FEFCO publishes two PDFs of the 12th edition: a 48-page overview (erected views and M/A
  flags) [S4] and a 145-page interactive edition with introduction, conventions and blank
  layouts [S20].
- The **11th edition** was published in **2007** [S19]; most older supplier catalogues reproduce
  it.
- On 2026-11-09 the FEFCO Code web page still offered the 12th edition as current; a note on
  the page says a "revised 12th edition" is coming soon, in the context of the Polish
  translation [S2]. No 13th edition was found. Recheck fefco.org before quoting "current
  edition" in a customer document.

## Relation between FEFCO and ESBO (solid board)

ESBO is the European Solid Board Organisation. The 11th edition was published jointly by FEFCO
and ESBO and covers corrugated and solid fibreboard cases [S19]. The 12th edition is titled for
corrugated board products and is published by FEFCO [S20]; ESBO's own page still refers to the
joint code [S3]. The same four-digit style number applies whichever board is used; the material
is specified separately. Rigid-type boxes (family 06) and some interior fittings are more common
in solid board, but the code does not restrict a style to one material.

## Structure of the four-digit number

The first two digits are the **series (family)**; the last two identify the style within that
series [S20][S12]. Example: 0201 is style 01 in series 02 (slotted boxes).

| Family | Name (12th edition) | What defines it |
|---|---|---|
| 01 | Commercial rolls and sheets | Rolls (0100) and cut sheets / blanks (0110 onward); not boxes. The 12th edition added 0112, 0113, 0119, 0121–0123, 0129 and 0130 [S4][S20] |
| 02 | Slotted boxes | Basically one piece with a glued, stitched or taped manufacturer's joint and top and bottom flaps; shipped flat and closed with their own flaps [S20][S19] |
| 03 | Telescopic boxes | Usually more than one piece (for example top and bottom) that fit over each other [S20] |
| 04 | Folder boxes and trays | Usually one piece; the bottom is hinged to form two or all side walls and the cover; locking tabs, handles and display panels may be included [S20] |
| 05 | Slide boxes | Several liners and sleeves that slide into each other in different directions; also covers outer sleeves for other cases [S20] |
| 06 | Rigid boxes | Two separate end pieces and a body, joined by stitching or a similar operation before use [S20] |
| 07 | Ready-glued cases | Basically one piece, shipped flat, ready to use after simple assembly [S20] |
| 08 | Retail and e-commerce packaging | **New in the 12th edition**: point-of-sale displays, trays and styles for online trade; codes 0801–0887, all marked new [S4][S20]. The 11th edition had no 08 series [S19] |
| 09 | Interior fitments | Liners, pads, partitions, dividers etc., either integrated in the box or separate; the number of panels shown is arbitrary [S20] |

The code notes that some designs could also be classified under another series; each is given
one number [S20][S19].

### Code suffixes and combinations

- **Style versions:** a derived version of a style takes a suffix. The 12th edition separates it
  with a dot (for example 0201.2, and codes such as 0229.1 or 0427.1 appear in the catalogue)
  [S20][S4]; the 11th edition used a dash (0201-2) [S19].
- **Joint suffix (12th edition):** "G" for a glued and "S" for a stitched manufacturer's joint,
  for example 0201-G [S20].
- **Combinations:** a box that mixes flap arrangements is written top/bottom, for example
  0204/0215 = top flaps as 0204 and bottom flaps as 0215 [S20][S19].
- **Fitments coded by panel count:** fitments may be coded 0982–0999 for 2 to 19 panels, for
  computer systems [S20][S19].

## Erection and closing codes (M, A, M/A)

Each design carries an erection flag: **M** = usually manual erection, **A** = usually automated
erection, **M/A** = either [S20]. The 11th edition also used **M+A** (a combination of both)
[S19]; the 12th-edition key lists only M, A and M/A, and styles flagged M+A in the 11th edition
are flagged M/A in the 12th (for example 0310) [S4][S19][S20]. Both editions note that some
manually erected cases can be closed automatically, citing 0216 and 0712 [S20][S19]. Check the
flag against the customer's case erector; the flags reflect current practice, not a rule.

## Dimension convention (L × W × H, inside)

- All dimensions are **internal dimensions in millimetres**, given as **Length × Width ×
  Height** [S20]. The 11th edition and FEFCO Recommendations 101 call the second dimension
  Breadth (B) [S19][S5]; the 12th edition calls it Width (W) [S20]. The meaning is the same.
- **Length** is the longer side of the opening, **Width/Breadth** the shorter side of the
  opening, and **Height** the distance from the top of the opening to the base [S20][S5].
  For some designs W can be numerically larger than L, so check the drawing [S20].
- The 12th edition adds **v**, a variable dimension defined by the design [S20].
- Dimensions should be measured on the **flat blank, from the centre of the crease**, allowing
  for the board thickness, under standard climate (23 °C, 50 % RH per EN 20187) [S20][S19].
- For overlapping outer flaps, the overlap (o) is given as a fourth figure after a slash, for
  example 355 × 205 × 120/40 mm [S20]. The 11th edition used the same form for the lid height
  (h) of telescope boxes [S19].
- Sheet sizes: first dimension along the flute glue lines, second across them [S20].
- The North American convention (FBA) is also length × width × depth, inside dimensions, where
  L and W are the opening; it is equivalent to FEFCO L × W × H [S6].
- The difference between inside and outside dimensions depends on board caliper; see
  `dimensional/` for allowances.

## Family 02 — slotted boxes

Slotted boxes are one piece, scored and slotted, with a manufacturer's joint that may be glued,
stitched or taped [S20]. US names follow the Fibre Box Association (FBA) [S6]. Erection flags
are from the 12th edition [S4].

| Code | Name (US / common) | Flap arrangement and closure | Flag |
|---|---|---|---|
| 0200 | Half slotted container (HSC) | An 0201 without top flaps [S6] | M/A [S4] |
| 0201 | Regular slotted container (RSC) | All flaps the same depth (half the width); outer flaps meet at the centre, inner flaps normally do not [S6][S12] | M/A [S4] |
| 0202 | Overlap slotted container (OSC) | Like 0201 but the outer flaps partially overlap [S6] | M/A [S4] |
| 0203 | Full overlap slotted container (FOL) | Outer flaps overlap to (nearly) the full width of the box [S6] | M/A [S4] |
| 0204 | Center special slotted container (CSSC) | Inner and outer flaps cut to different depths so both pairs meet at the centre [S6] | M/A [S4] |
| 0205 | Center special overlap slotted container | Inner flaps meet; outer flaps partially overlap [S6] | M/A [S4] |
| 0206 | Center special full overlap slotted container | Inner flaps meet; outer flaps fully overlap [S6] | M/A [S4] |
| 0209 | Open-top slotted box with short inturned top flaps (descriptive) | Bottom flaps as 0201; the top flaps are short (depth h) and fold inward to form a narrow rim, leaving most of the top open [S19][S4] | M/A [S4] |
| 0210 | Slotted box with hinged tuck lid and tuck base (descriptive) | One long panel carries full-size top and bottom flaps with rounded tuck edges that close over the whole opening; the end panels carry small dust flaps; the other long panel has no flaps [S19] | M [S4] |
| 0215 | Slotted box with interlocking bottom (vendor term "Swedish" or lock bottom) | Shaped bottom flaps folded in sequence to interlock, no tape [S12][S19] | M [S4] |
| 0216 | Slotted box with interlocking bottom, RSC-style top (descriptive) | Bottom flaps are shaped to interlock (manual erection); the top flaps are 0201-type, and the code notes the top can be closed automatically [S19][S20] | M [S4] |
| 0225 | Slotted box with unequal bottom flaps (descriptive) | Top flaps as 0201. Bottom: end-panel flaps of reduced depth h (h ≤ H) and one full-width flap with a finger notch on one long panel, per the blank drawing [S19]. Purpose of the extended flaps is not stated in the code. **VERIFY** with converter drawing | M [S4] |
| 0226 | Slotted box with webbed (gusseted) end-flap corners (descriptive) | The flaps on the end panels carry diagonal creases, so adjacent flaps are joined at the corners instead of being slotted apart; the closed top shows sloping ends [S19] | M [S4] |
| 0227 | Slotted box with tab-locked outer flaps (descriptive) | 0201-type flaps where the outer flaps carry a notch and the inner flaps small tabs, so the closure locks without tape; drawn as a tall case [S19] | M [S4] |
| 0228 | Slotted box with integral centre divider (descriptive) | The blank starts and ends with a half-length panel (½L), so the joint falls in the middle of a long side; the drawing shows an internal divider along the length [S19] | M/A [S4] |
| 0229 | Slotted box with double-creased flaps (descriptive) | Flaps carry an extra crease parallel to the body score; bottom flaps are ½L deep; the drawing shows the outer top flaps folded at the extra crease [S19]. Purpose (reinforced or reclosable closure) not stated. **VERIFY** | M [S4] |

The 12th edition also has 0207, 0208, 0211, 0212, 0214, 0217, 0218, 0230, 0231 and new codes
0219–0222, 0229.1, 0232, 0233, 0233.1 and 0240–0242 (the last three drawn as tall boxes with a
hang tab) [S4]. Joint type for all 02 styles is chosen in the order, not by the code number
[S20].

## Family 05 — slide boxes

Slide boxes are several pieces (liners and sleeves) that slide into each other; the series
also covers outer sleeves for other cases [S20].

| Code | Name | Construction (all M [S4]) |
|---|---|---|
| 0501 | Sleeve open on the L × W faces (descriptive) | A four-panel band (L, W, L, W) of height H, open at top and bottom; it slides over a case or tray vertically [S19] |
| 0502 | Sleeve open on the W × H faces (descriptive) | A four-panel band (L, H, L, H) of width W, open at both ends; the inner part slides in along the length [S19] |
| 0503 | Sleeve open on the L × H faces (descriptive) | A four-panel band (W, H, W, H) of depth L, open on the two long sides [S19] |

The three differ only in which pair of faces is left open (the slide direction). Further codes
0504–0512 combine sleeves with trays and liners [S4][S19].

## Family 06 — rigid boxes

Rigid boxes (in the FEFCO sense, not the paper-wrapped "set-up" boxes of the luxury trade) are a
body plus two separate end pieces, stitched or otherwise joined before use [S20].

| Code | Construction | Flag |
|---|---|---|
| 0601 | One body blank wraps base, front, lid and back (lid hinged, with flanges); two flat end panels (W × H) are stitched to flanges on the body [S19] | A [S4] |
| 0605 | As the rigid body of 0601 but the two end pieces have their own flanges folded round the body; the lid is a full flap [S19] | A [S4] |

Other 06 codes: 0602, 0606–0608, 0610, 0615, 0616, 0620, 0621 [S4]. These styles are common in
solid board for heavy, returnable or wet-strength packs.

## Family 07 — ready-glued cases

Ready-glued cases are one piece, glued by the converter, shipped flat and erected by a simple
movement, often with an automatic ("crash-lock") bottom [S20][S13].

| Code | Name (US / common) | Construction | Flag |
|---|---|---|---|
| 0700 | Pre-glued self-erecting tray (descriptive) | Open tray with no top flaps and a glued automatic (crash-lock) bottom; drawn flat-folded and erected [S19] | M [S4] |
| 0711 | Crash-lock (automatic) bottom box | Glued automatic bottom; top closed with 0201-type flaps [S11][S19] | M [S4] |
| 0712 | Crash-lock bottom box with centre-meeting top flaps (descriptive) | Glued automatic bottom; top flaps sized so all four meet at the centre (½W and ½L depths); the code notes it can be closed automatically [S19][S20] | M [S4] |
| 0713 | Crash-lock bottom box with hinged tuck lid (descriptive) | Glued automatic bottom; one long panel carries a full lid with tuck edge, the end panels carry dust flaps [S19][S11] | M [S4] |
| 0715 | Crash-lock bottom box with integral cell dividers (descriptive) | Glued automatic bottom whose extended flaps form internal partitions (bottle-carrier style); 0201-type top flaps [S19] | M [S4] |
| 0747 | Ready-glued hinged-lid box with gusseted ends (descriptive) | Lid with tuck front; the end walls carry diagonal folds so the glued box folds flat and erects in one movement [S19] | M [S4] |

The 12th edition expanded the series heavily (new codes include 0702, 0704–0710, 0719–0728, 0730 and
0740) [S4].

## Family 08 — retail and e-commerce packaging (new in the 12th edition)

Series 08 holds point-of-sale displays and trays and styles for online trade [S20]. All its
codes are new in the 12th edition: 0801–0804, 0808, 0809, 0815–0819, 0825, 0826, 0830–0834,
0840–0843, 0845–0854, 0858–0861, 0865, 0866, 0870–0874, 0880–0882, 0885–0887; all are flagged
M except 0802 (M/A) [S4]. Individual drawings are in [S20]; descriptions have not yet been
added to this file.

## Family 09 — interior fitments

Interior fitments are liners, pads, partitions and dividers, either integrated into the box or
separate [S20]. They are specified with the outer case (for example "0201 + 0933"). The number
of panels or cells drawn is **arbitrary** and may be increased or decreased [S20].

| Code | Construction (own description of the drawing) | Flag |
|---|---|---|
| 0900 | Flat pad laid on the closed flaps inside the case (top and bottom pads) [S19] | M/A in the 12th edition [S4]; M in the 11th [S19] |
| 0901 | Flat horizontal layer pad (L × W) inside the case [S19] | M/A [S4] |
| 0902, 0903 | Flat vertical divider pad across the width (0902) or along the length (0903) [S19] | M/A [S4] |
| 0904–0910 | Scored liners folded to cover two or more inside faces (walls, base, top) in various combinations [S19] | M/A [S4] |
| 0913 | Folded liner with bevelled corner panels (corner buffers) [S19] | M [S4] |
| 0914 | Four-panel inner sleeve (tube) [S19] | M [S4] |
| 0920 | Folded insert forming two cells [S19] | M [S4] |
| 0933 | Slotted (interlocking) partition: drawn as 2 long pieces with 3 slots and 3 short pieces with 2 slots, giving 3 × 4 = 12 cells [S19] | M [S4] |
| 0934 | Slotted partition: drawn as a larger grid of about 5 × 7 = 35 cells (4 long and 6 short pieces as labelled) [S19]. Vendor "fifteen cell" name does not match the drawing. What distinguishes 0934 from 0933 other than the drawn cell count is not stated, and panel counts are arbitrary [S20]. **VERIFY** | M [S4] |
| 0935 | Slotted partition like 0933 (12 cells) where one piece is drawn taller than the others (a high divider) [S19] | M [S4] |

## How to use FEFCO codes in a specification

1. Give the code, the inside dimensions in L × W × H order in mm, the board grade, the flute
   and the manufacturer's-joint type (glued, stitched or taped; 12th edition suffix -G or -S)
   [S20].
2. Say whether dimensions are inside (FEFCO default) or outside; never assume [S20][S5].
3. For mixed flap styles use the top/bottom form (for example 0204/0215) [S20].
4. Name any fitment by its 09 code, together with the outer case code.
5. Check the M / A erection flag against the customer's line [S4].
6. The FEFCO Code gives drawings, not names: for styles described here as "descriptive" or
   marked **VERIFY**, attach the converter's drawing.
